## 宣传里的“CN2”，要看是哪一段

雨云的线路是方向不对称的：去程电信走普通 163 骨干、联通走 AS4837、移动走 CMI；回程电信换成 CN2、联通仍是 AS4837、移动仍是 CMI。所以“电信 CN2 回程”这个说法是准确的，优化发生在回国这一段，出国那一段没有特殊待遇。

实测延迟也印证了这个结构。277 个国内测点平均 72ms，拆开看：联通 55ms、移动 71ms、电信 90ms。联通反而最快，因为去回程都是 AS4837 直连，路径最短；电信虽然有 CN2 回程兜底，去程走 163 还是拖了一点。港澳台方向平均 41ms，是这批数据里最好的一组。

结论很直接：主力用户在联通网络，这台机器性价比最高；移动用户体感居中；电信用户能用，晚高峰稳定性靠回程 CN2 撑着，但别指望它是三网里最低延迟的那个。如果你的用户主要在电信，又对延迟敏感，值得先月付一个月自己测一遍再决定要不要长用。
